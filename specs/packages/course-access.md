# course-access: 课程观看资格

## 意图

规定现有学堂签发播放地址、展示观看入口和读取本地视频的行为。
本包描述报名功能加入前的观看规则。

## 外部行为

### course-access-1

当客户端请求课程的新播放地址时，学堂应仅向已登录且所请求课程已发布的用户返回播放地址及其到期时间：

| 状态 | 结果 |
| --- | --- |
| 未登录 | 返回 401，不返回播放地址 |
| 已登录，课程不存在或未发布 | 返回 404，不返回播放地址 |
| 已登录，课程已发布 | 返回播放地址和到期时间，有效期 60 秒 |

- 课程取消发布后，不再为它签发新地址。

### course-access-2

当浏览器打开已发布课程的详情页时，学堂应按签发播放地址的同一资格判定展示观看入口 [[course-access-1](#course-access-1)]：

| 状态 | 观看入口 |
| --- | --- |
| 未登录 | 登录入口，登录后回到本页 |
| 已登录 | “开始观看”按钮，点击后通过签发接口取得播放地址再播放 |

- 页面本身不包含播放地址。

### course-access-3

给定播放地址由学堂签发且尚未到期，当客户端读取该地址时，学堂应返回对应课程的视频内容，支持按字节范围读取，且不要求登录会话。

### course-access-4

当客户端读取签名无效或已到期的播放地址时，学堂应拒绝返回视频内容：

| 情形 | 结果 |
| --- | --- |
| 签名、到期时间或课程编号被改动，或缺少签名 | 返回 403 |
| 播放地址已到期 | 返回 410 |

### course-access-5

当客户端绕过播放地址，按文件名或其他路径直接请求视频文件时，学堂应拒绝返回视频内容。

### course-access-6

如果正在播放，当浏览器因播放地址到期而读取视频失败时，课程页应重新请求播放地址 [[course-access-1](#course-access-1)]，并从当前进度继续播放。

## 验证

### course-access-7

当对学堂执行签发集成测试时，测试应以未登录、已登录且课程未发布或不存在、已登录且课程已发布、课程取消发布后四种情形请求播放地址，并核对状态码和是否返回地址 [[course-access-1](#course-access-1)]。

### course-access-8

当对学堂执行课程页集成测试时，测试应分别以未登录和已登录身份打开课程详情页，核对观看入口与页面中不含播放地址 [[course-access-2](#course-access-2)]。

### course-access-9

当对学堂执行媒体读取集成测试时，测试应用实际签发的地址在不带会话时按字节范围读取视频，并以改动签名、到期时间、课程编号和缺少签名的地址核对返回 403 [[course-access-3](#course-access-3)] [[course-access-4](#course-access-4)]。

### course-access-10

当对学堂执行素材隔离集成测试时，测试应按文件名和目录穿越路径直接请求视频，并核对响应中没有视频内容 [[course-access-5](#course-access-5)]。

### course-access-11

当对学堂执行续播集成测试时，测试应让播放地址到期后核对读取返回 410，再请求新地址并从后续字节范围继续读取 [[course-access-4](#course-access-4)] [[course-access-6](#course-access-6)]。
